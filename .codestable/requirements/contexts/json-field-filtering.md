# JSON 字段筛选领域上下文

从任意 JSON 数据里按字段选择抽取结果，同时给用户一份可复制的筛选代码。

## 通用语言

**字段路径**：以 `json` 为根的取值路径（如 `json.data`）；非标识符属性名用方括号访问。

**指定层级筛选**：只在字段路径指向的数据上抽取选中字段。

**递归深度筛选**：不限定路径，在整棵 JSON 树里查找含选中字段的对象或收集其值。

**字段选择**：需要抽取的字段名列表；为空表示不抽取任何内容。

**输出格式**：`object` 保持每个来源对象的字段映射，`grouped` 按字段收集值。

**生成代码**：本次筛选对应的 JavaScript 片段，供用户复制使用。

**高级筛选**：在字段选择之外的附加处理 — 按字段去重、按条件过滤字段值。

## 稳定规则

- 字段路径以 `json` 为根；非法标识符属性在生成代码里用方括号访问，保证代码可直接运行。
- 指定层级筛选只处理路径指向的数据：数组逐元素映射，对象直接取字段；路径指向的既不是数组也不是对象时必须报错，不得静默返回空结果。
- 递归深度筛选按字段名在整棵树上匹配；对象格式只保留命中字段非空的对象，分组格式按字段收集全部同名值。
- 字段选择为空时返回空结果（`object` 为空数组、`grouped` 为空对象），不视为错误。
- `grouped` 与 `object` 是同一次筛选的两种表示，字段选择与路径不变时两者必须描述同一批数据。
- 预览结果必须由解析生成代码得到，不执行任何动态代码；生成代码与预览结果不得出现语义分叉。
