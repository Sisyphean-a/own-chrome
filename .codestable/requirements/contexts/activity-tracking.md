# 浏览活动追踪领域上下文

按用户配置的目标规则，追踪浏览器里的页面交互与系统活跃时长，并把结果按日聚合成可回看的日志。

## 通用语言

**目标规则**：决定哪些 URL 被追踪的配置项；类型为 `exact` 时按 URL 全等匹配，类型为 `domain` 时按通配符匹配。

**被追踪页面**：命中当前任一条目标规则的 URL；未命中的页面不进入追踪。

**会话**：一段连续的被追踪页面停留；由 tabId、URL、标题、开始/结束时间、心跳次数和系统活跃时长构成。

**心跳**：被追踪页面按固定间隔上报的存活信号，只有与当前会话的 tabId 和 URL 同时一致才被接受。

**页面交互时长**：由心跳次数与心跳间隔推导出的时长，不代表逐事件计时。

**系统活跃时长**：会话期间浏览器聚焦且系统未空闲所累计的时长。

**按日聚合日志**：以本地日期为键存储的聚合结果。

**概览**：读取聚合日志并展示分组、时间线的只读页面。

## 稳定规则

- 只有命中目标规则的页面才计入追踪；`domain` 规则的通配符只允许 `*`，其余正则元字符按字面处理。
- 同一时刻最多一个活动会话；tabId 或 URL 变化、规则不再命中、浏览器失焦或系统空闲都会结束当前会话。
- 心跳归属由 tabId 与 URL 同时决定；不匹配当前会话的心跳不得计入，也不能改变会话标识。
- 页面交互时长是心跳推导值，系统活跃时长是上下文时间差累加值；二者不可混用，也不得当作精确计时。
- 聚合只发生在后台；内容脚本、选项页和概览页都不维护追踪状态，概览只读聚合日志。
- 日志按本地日期分桶，配置与运行时状态分开存放于不同存储键。
